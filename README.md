# Textmood package
This is the first assignment for submission from the Intermediate R course.

I chose to develop an R package with three functions to analyze a text and determine the amount of positive and negative words that contains.
I am aware of some caveat of the function's design as once I have converted my text into a vector, the way I match positive and negative words can create false positives and miss other words. This can be improved in future times. But for now, the package is developed and it has been successfully run by a user (including the download from this repository).
